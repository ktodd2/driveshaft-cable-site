# Customers.jsx

## Purpose

Landing page section component that displays target customer segments for driveshaft cable products. Renders a grid of customer type cards with icons, titles, and descriptions showcasing industries like heavy-duty towing, fleet maintenance, roadside service, and municipal fleets.

## Exports

- `Customers` (default) - React component rendering the "Who It's For" section with a 6-item grid of customer types
