# Logo assets

The site references each file by exact filename:

| Filename               | Used in                                                                |
|------------------------|------------------------------------------------------------------------|
| `main-logo.png`        | Header (every page) + Admin Login + Open Graph / Twitter social card   |
| `logo-badge.png`       | Footer brand column                                                    |
| `icon.png`             | Favicon + every admin page's sidebar tile                              |
| `logo-horizontal.png`  | Currently unused (kept as a horizontal alternate for future)           |
| `logo-badge-light.png` | Currently unused (light-background variant of the badge, for reserve)  |

Recommended sizing (not enforced):
- `main-logo.png` — about 1920×850 (~2.3:1), dark background, the dramatic banner is the brand hero
- `logo-badge.png` — about 600×600, dark background
- `icon.png` — at least 512×512, square
- `logo-horizontal.png` — about 800×200, horizontal alternate
- `logo-badge-light.png` — same shape as `logo-badge.png`, white/light background

If a referenced file is missing, the affected logo renders as a broken image. Other images in `public/` (the IMG_*.jpeg product photos, `inuse.jpeg`, etc.) are unrelated to branding.

This README can be deleted at any time.
